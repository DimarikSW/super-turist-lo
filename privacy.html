Политика конфиденциальности

Эта политика относится к игре Super Turist, доступной по адресу https://dimariksw.github.io/super-turist-lo/.

Какие данные мы собираем

Игра не собирает, не хранит и не передаёт персональные данные: имя, адрес, телефон, платежи — ничего из этого не запрашивается. Игровой прогресс сохраняется только локально на вашем устройстве и никуда не отправляется.

Сторонние сервисы

Игра размещена на GitHub Pages. При открытии страницы GitHub может обрабатывать технические данные (IP-адрес, сведения о браузере) в соответствии со своей собственной политикой конфиденциальности. Игра никаких дополнительных скриптов аналитики и рекламы не подключает.

Дети

Игра не собирает данные о возрасте и не содержит контента, ограниченного по возрасту.

Изменения политики

Если политика изменится, её новая версия будет опубликована на этой странице.
